# ADR 0005: Раскладка vault, префиксы S3 и имена файлов

* **Статус:** принято
* **Дата:** 2026-11-16
* **Основание:** ТЗ §4.1, §11, §14.3; решения пользователя от 2026-11-16

## Контекст

Пользователь указал: префикс vault — `vault4-kb01`, плагин синхронизации — Remotely Save
0.5.25, рубрикатор начинается с `Inbox`.

## Решение

### Префиксы в bucket `obsidian-kb01`

```text
vault4-kb01/     ← синхронизируется с Obsidian
archive/         ← технический архив оригиналов, вне vault
backup/          ← резервные копии и предыдущие версии заметок
```

Корень bucket не используется. Точные имена префиксов нормализуются приложением
(завершающий слэш добавляется автоматически).

### Внутри vault

```text
vault4-kb01/
  Telegram/
    Inbox/
    <Тема>/
      <Подтема>/
        <slug>-<kb_id-суффикс>.md
  Knowledge/                 ← пользовательские материалы, приложение не пишет
  Review/
    <kb_id>/
      <proposal_id>.md
  Attachments/
    Telegram/
      <attachment_id>/
        <безопасное-имя-файла>
```

* Стартовое состояние рубрикатора: всё попадает в `Inbox/`; темы добавляются в
  `config/rubricator.yaml` позже (Этап 5).
* `Knowledge/` и `.obsidian/` приложение не создаёт и не изменяет.
* Путь после первой публикации **не меняется автоматически** при повторной классификации.

### Имена файлов

* `slug = slugify(title, allow_unicode=True)` + короткий суффикс из `kb_id`
  (последние 6 символов uuid) → `название-материала-a1b2c3.md`.
* Запрещённые Windows символы заменяются; длина проверяется `pathvalidate`;
  при превышении — обрезка slug с сохранением суффикса (уникальность важнее полного названия).
* Коллизии с учётом регистра разрешаются добавлением символов суффикса.
* Оригинальное имя вложения сохраняется в метаданных БД; в ключе S3 используется
  `<attachment_id>/<безопасное-имя>` — переименование пользователем не ломает ссылку.

## Последствия

* Ссылки в заметках относительные (`../../Attachments/Telegram/…` или короткие), не presigned URL.
* При перемещении заметки в Obsidian путь в БД обновляется сверкой по `kb_id`,
  файл по старому пути не восстанавливается.
* Смена префикса vault — конфигурационная операция, требующая повторной сверки;
  в коде префикс не хардкодится.

## Проверка

* Кириллица и emoji в ключах S3 подтверждены спайком (`docs/s3-obsidian.md`).
* Совместимость с Remotely Save и появление файлов на устройстве — **не проверено**,
  чек-лист в `docs/s3-obsidian.md` §3.
