# Отчёт: рубрикатор, группировка, тонкий front matter

Дата: 2026-11-16. Объём: пункты 1, 2, 4 плана Этапа 5, **без LLM**.
Основание: ТЗ §9, §11, §12 (частично), ADR 0006, ADR 0007.

## Что сделано

| Область | Результат |
|---|---|
| Front matter | 2 поля (`kb_id`, `created_at`), `tags` — только при наличии |
| Рубрикатор | `config/rubricator.yaml`, валидация, классификация по правилам, `Inbox` по умолчанию |
| Группировка | сигналы `joined` и `reply`; предложения в `Review/`; альбомы недоступны в HTML |
| Диагностика | `doctor` проверяет рубрикатор |
| CLI | `kbcollector groups [--publish] [--limit N] [--sample N]` |

## Применено к реальному vault

* **839 заметок** переписаны на новый front matter. Механизм: только после сверки
  sha256 содержимого объекта с БД; путь заметки должен совпасть с пересчитанным.
  Итог: `updated: 839, unchanged: 0, skipped: 0`.
* **229 предложений** объединения опубликованы в
  `vault4-kb01/Review/<kb_id>/group-*.md`:
  113 `joined_run` + 116 `reply_chain`.
* Рубрикатор активен: `doctor` → `rubricator ok, версия 1, default=Inbox, категорий: 1`.
* Все материалы остаются в `Inbox`: правила пока пустые, темы добавляются вручную.

## Как пользоваться

```powershell
uv run kbcollector groups               # только показать кандидатов
uv run kbcollector groups --publish     # записать предложения в Review/
uv run kbcollector import-html          # при появлении правил категории применятся к новым заметкам
```

Рубрикатор:

```yaml
version: 1
default: Inbox
rules:
  - category: Разработка/Python
    any: [python, django, fastapi]
```

## Ограничения

* Группировка — **предложения**, автоматического слияния нет (ТЗ §4.4). Применение
  предложений (с сохранением предыдущей версии и проверкой `If-Match`) — следующий шаг.
* `reply_chain` может объединять содержательный самостоятельный ответ: это кандидат,
  а не решение.
* Альбомы в HTML не размечены — появятся только на live-приёме.
* Классификация без LLM — только по ключевым словам; семантическая рубрикация
  и заголовки/резюме остаются на этап с LLM (0 токенов потрачено).
