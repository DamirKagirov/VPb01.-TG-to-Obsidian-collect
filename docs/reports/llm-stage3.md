## Найденные и исправленные проблемы

1. **Обрезанный JSON.** Модель упиралась в `max_tokens=400` (reasoning + ответ) и отдавала
   невалидный JSON — 30 заметок. Повтор срабатывал только при пустом `content`.
   Исправлено: лимит по умолчанию 800, повтор с 2000 при `finish_reason=length` даже
   для непустого ответа. Коммит `3491db3`, тест на повтор.
2. **S3 рвёт соединения при плотном потоке.** Публикация 813 предложений подряд
   (~7 запросов/с) дала 379 ошибок `Connection was closed`. При обычном темпе
   (между вызовами модели) сбоев почти не было.
   Исправлено: повтор записи до 3 раз с backoff (1 с, 2 с) и пауза 0,2 с между
   публикациями; запись идемпотентна благодаря `If-None-Match`. Коммит `3491db3`.

## Замечания по качеству

* Короткие и мусорные сообщения («привет», «хз», ссылка без текста) получают описательные
  заголовки и `Inbox` с уверенностью 0.20 — безвредно, но малополезно.
* 227 `Inbox` — в основном такие сообщения и пограничные темы; при `confidence < 0.5`
  категория принудительно `Inbox`.
* Теги иногда склеиваются (`голосовыеботы`): модель отдаёт их без пробела, нормализация
  не может восстановить границу слова.
* `summary` не генерируется: поле убрано из схемы этапа 1.

## Что не сделано

* Применение предложений (`proposals apply`) — нужен отдельный этап с `If-Match`,
  бэкапом и конфликтами (ADR 0002).
* Обогащение при импорте новых материалов (`import-html`) — отложено.
* 26 заметок без текста (медиа без подписи) обогащать нечем.

## Следующий шаг

Ревью предложений в `Review/` и реализация `proposals apply`. Бюджет исчерпан на 94,9%:
на повторные прогоны и эксперименты остаётся ~36 тыс. токенов.
